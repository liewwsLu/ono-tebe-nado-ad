# Оно тебе надо

Учебный проект: адаптивная вёрстка страницы аукциона вещей, в которые никто не верил.

## Структура

- `index.html` — разметка страницы.
- `styles/global.css` — сброс и общие стили (предоставлены в заготовке).
- `styles/style.css` — стили блоков: шапка, обложка, лоты, «Об аукционе», подвал.
- `fonts/` — шрифт Raleway (подключён через `fonts/fonts.css`).
- `images/` — изображения и иконки.

## Запуск

Откройте `index.html` в браузере.
