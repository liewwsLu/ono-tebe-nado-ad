# Оно тебе надо

Проектная работа Яндекс Практикума: одностраничный сайт аукциона вещей, в которые никто не верил.

Ссылка на репозиторий: https://github.com/liewwsLu/ono-tebe-nado-ad

## Что сделано

- Семантическая разметка: `header`, `main` с тремя секциями, `footer`, `nav`, `address`, `article`.
- Шапка свёрстана на гридах (`1fr min-content 1fr`), логотип стоит ровно по центру.
- Обложка с фоновым изображением и переиспользуемым оверлеем, заголовок с выравниванием строк и межбуквенным расстоянием.
- Карточки лотов на флексбоксе: при добавлении четвёртой карточки она переносится на новую строку.
- Секция «Об аукционе» на гридах, отступ между абзацами задан через `gap`.
- Подвал на гридах: адрес, меню и ссылки на соцсети.
- Шрифт Raleway подключён локально через `@font-face`.

## Структура

- `index.html` — разметка страницы.
- `fonts/` — шрифты и файл с их подключением.
- `styles/global.css` — общие стили из заготовки.
- `styles/style.css` — стили блоков страницы.
- `images/` — изображения и иконки.

## Как открыть

Скачать репозиторий и открыть `index.html` в браузере.
